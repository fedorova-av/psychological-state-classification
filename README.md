# Классификация психологических состояний по тексту

 Определение одной из шести меток по тексту обсуждения - депрессия, тревожное расстройство, БАР, ПРЛ, ОКР или шизофрения.

**Лучший сохранённый результат финального каскада: Macro F1 = 0,8513.** Accuracy - 0,912. 

## Решение

1. Восстановление обсуждений по ссылкам и порядку строк; очистка, удаление точных дубликатов и лемматизация.
2. Разделение train/test по обсуждениям: одно обсуждение не попадает в обе части.
3. Объединение сообщений обсуждения в один документ. Основная модель - TF-IDF + LinearSVC с балансировкой классов.
4. Выбор гиперпараметров через 5-fold CV и настройка сдвигов решений по OOF-прогнозам на train.
5. Два бинарных каскада уточняют прогнозы для пар ПРЛ/депрессия и БАР/депрессия.

В финальном эксперименте после очистки осталось **60 406 сообщений**: 44 933 в train и 15 473 в test.

## Запуск

Рекомендуется отдельное окружение Python 3.10+:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate
python -m pip install numpy pandas scikit-learn pymorphy3 razdel nltk joblib jupyter
python -m nltk.downloader stopwords
jupyter notebook final_notebook.ipynb
```

Положите `Data_Sources_csv.csv` рядом с ноутбуком или измените `DATA_PATH` в первой ячейке. Файл содержит тексты из b17.ru, ВКонтакте и Reddit. Разделитель — `;`, необходимые колонки: `text`, `tag`, `url`, `source`. Сохраняйте исходный порядок строк: он используется для восстановления обсуждений ВКонтакте. Данные и обученная модель не включены в репозиторий.

Выполните ячейки сверху вниз. По умолчанию `N_JOBS = 1`, чтобы ограничить расход памяти. Лемматизация и подбор 32 конфигураций по пяти фолдам могут занять значительное время. После выполнения создаётся `final_model.joblib`; в конце ноутбука есть функция `predict_discussion` для полного текста нового обсуждения.
