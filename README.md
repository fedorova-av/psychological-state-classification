# Классификация психологических состояний по тексту

Учебный NLP-проект: определение одной из шести меток по тексту обсуждения — депрессия, тревожное расстройство, БАР, ПРЛ, ОКР или шизофрения.

**Лучший сохранённый результат финального каскада: Macro F1 = 0,8513.** Accuracy — 0,912. Метрики рассчитаны по сообщениям тестовой выборки: всем сообщениям одного обсуждения присваивается общий прогноз.

## Решение

1. Восстановление обсуждений по ссылкам и порядку строк; очистка, удаление точных дубликатов и лемматизация.
2. Разделение train/test по обсуждениям: одно обсуждение не попадает в обе части.
3. Объединение сообщений обсуждения в один документ. Основная модель — TF-IDF + LinearSVC с балансировкой классов.
4. Выбор гиперпараметров через 5-fold CV и настройка сдвигов решений по OOF-прогнозам на train.
5. Два бинарных каскада уточняют прогнозы для пар ПРЛ/депрессия и БАР/депрессия.

В финальном эксперименте после очистки осталось **60 406 сообщений**: 44 933 в train и 15 473 в test. Это версия с классификацией целых обсуждений; она отличается от ранних экспериментов на отдельных репликах.

## Файлы

- [final_notebook.ipynb](final_notebook.ipynb) — полный путь от исходного CSV до финального каскада, оценки и сохранения модели.

## Запуск

Рекомендуется отдельное окружение Python 3.10+:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate
python -m pip install numpy pandas scikit-learn pymorphy3 razdel nltk joblib jupyter
python -m nltk.downloader stopwords
jupyter notebook final_notebook.ipynb
```

Положите `Data_Sources_csv.csv` рядом с ноутбуком или измените `DATA_PATH` в первой ячейке. Файл содержит тексты из b17.ru, ВКонтакте и Reddit. Разделитель — `;`, необходимые колонки: `text`, `tag`, `url`, `source`. Сохраняйте исходный порядок строк: он используется для восстановления обсуждений ВКонтакте. Данные и обученная модель не включены в репозиторий.

Выполните ячейки сверху вниз. По умолчанию `N_JOBS = 1`, чтобы ограничить расход памяти. Лемматизация и подбор 32 конфигураций по пяти фолдам могут занять значительное время. После выполнения создаётся `final_model.joblib`; в конце ноутбука есть функция `predict_discussion` для полного текста нового обсуждения.

## Результаты и ограничения

| Метрика исходного финального запуска | Значение |
| --- | ---: |
| Macro F1 по сообщениям | **0,8513** |
| Accuracy по сообщениям | 0,912 |
| Weighted F1 по сообщениям | 0,910 |
| Сообщений в test | 15 473 |

Источник чисел — сохранённый вывод финальной ячейки исходного `final_notebook.ipynb`. В этом репозитории оставлен только путь финального решения. Исторический отчёт сохранён отдельно в Markdown-ячейке; вычислительные выводы очищены. Сокращённый ноутбук проверен на синтаксис и зависимости между ячейками, но полное переобучение при подготовке репозитория не выполнялось. Точные версии исходных библиотек не сохранены, поэтому повторный запуск может дать несколько иные значения.

В исходной работе тестовая выборка просматривалась при сравнении вариантов и выборе каскадов. Поэтому 0,8513 — результат исследовательского эксперимента, а не оценка на новом, ранее не использованном holdout. Для независимого подтверждения нужен новый набор обсуждений. В сокращённой версии test оценивается только после обучения финального каскада.

Обсуждения восстанавливаются эвристически. У двух обсуждений в исходном запуске обнаружены разные метки: при стратификации используется первая, при обучении — наиболее частая. Оценка по сообщениям придаёт больший вес длинным обсуждениям; ноутбук дополнительно вычисляет Macro F1 по обсуждениям. Метки отражают разметку источников и не являются медицинским диагнозом.
